# Find Rides

A collaborative rideshare project developed through the Technology Department of UIUC Chinese Students and Scholars Association.

## Features

- Browse and post rides.
- Account and profile interfaces.
- Ride history and saved-ride pages.

## My Contribution

Backend development and integration work.

## Structure

- `src/`: React interface.
- `public/`: Static assets.
- `server/`: Backend code.

This repository is a fork of the original team project.

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).
